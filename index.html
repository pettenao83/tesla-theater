Collega YouTube Music

Serve un ID client gratuito di Google, da creare una volta sola:

  1. Apri console.cloud.google.com e crea un progetto.
  2. In API e servizi → Libreria abilita YouTube Data API v3.
  3. In Schermata consenso OAuth scegli Esterno e aggiungi il tuo account Google tra gli utenti di test.
  4. In Credenziali → Crea credenziali → ID client OAuth scegli Applicazione web. Come origine JavaScript metti e come URI di reindirizzamento metti
  5. Copia l'ID client qui sotto.
